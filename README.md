# Zinzi May | Portfolio

Personal portfolio of **Zinzi May**, Digital Associate at Capaciti, Cape Town. It showcases the projects, certificates and CV from my AI and data science bootcamp, where I chose software development as my specialisation track.

**Live site:** https://zinzi-hub.github.io/Zinzi-may/

## What's on the site

- About me, experience and education
- Four projects, each with my role, technologies, and links to the code and live demo
- Certificates, with links to the PDFs
- A downloadable CV
- An "Ask about Zinzi" quick-answer section
- Contact details

## Projects

| Project | My role | Technologies |
|---|---|---|
| **CareerBuddySA** | Backend developer (group project) | AI, backend, Lovable |
| **AI Budget Planner** | Researcher (group project) | Next.js 14, React, TypeScript, Tailwind CSS, Supabase, Groq API, Recharts, jsPDF, Vercel |
| **WC Hospital Feedback** | UI designer (group project) | Next.js 14, TypeScript, Supabase (PostgreSQL + Auth), Groq AI |
| **Work Flow Whisperer** | Solo project | Tailwind CSS, prompt engineering, Lovable AI, GitHub |

- CareerBuddySA: an AI career mentor that helps South African Grade 9 to 12 pupils explore careers and subject choices.
- AI Budget Planner: a budgeting app for young adults with AI spending analysis, savings goals and PDF reports.
- WC Hospital Feedback: a secure app for collecting and analysing patient feedback for the Western Cape Department of Health.
- Work Flow Whisperer: a tool that automates repetitive tasks and improves professional workflows.

## Built with

HTML, CSS and vanilla JavaScript in a single `index.html`. There are no frameworks or build steps. It supports light and dark mode and works on mobile screens.

## Repository structure

```
Zinzi-may/
├── index.html            # the portfolio site
├── Zinzi_May_Resume.pdf  # CV (linked from the Download CV button)
└── README.md
```

## Run it locally

1. Clone the repo: `git clone https://github.com/zinzi-hub/Zinzi-may.git`
2. Open `index.html` in any browser.

## Deployment

Hosted on GitHub Pages, deployed from the `main` branch. Any commit to `main` redeploys the site within a couple of minutes.
